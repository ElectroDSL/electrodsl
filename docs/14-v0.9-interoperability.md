# ElectroDSL 0.9 interoperability and CI

ElectroDSL 0.9 makes production-quality results consumable by common engineering and software-delivery systems.

## Quality output formats

```powershell
node packages/cli/dist/index.js project check examples/project-v09 --format text
node packages/cli/dist/index.js project check examples/project-v09 --format json
node packages/cli/dist/index.js project check examples/project-v09 --format sarif
node packages/cli/dist/index.js project check examples/project-v09 --format junit
```

SARIF output follows SARIF 2.1 and can be consumed by code-scanning platforms. JUnit XML works with common CI test-report viewers. Both preserve ElectroDSL diagnostic codes and severity; SARIF also carries source locations when available.

## Production interchange artifacts

Every successful build includes:

- `quality.sarif` for static-analysis integrations;
- `quality.junit.xml` for CI test reporting;
- `project.json` containing the complete canonical project IR;
- all drawings, schedules, connectivity analysis, and integrity manifests from earlier releases.

These files are listed in `artifacts.json` and protected by SHA-256 digests.

The repository CI workflow builds and tests every package, checks the v0.9 reference project, verifies its artifacts, and uploads the interchange outputs.
