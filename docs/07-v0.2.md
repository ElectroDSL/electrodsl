# ElectroDSL 0.2

ElectroDSL 0.2 adds electrically meaningful nets, explicit junctions, route preferences, terminal validation, and obstacle-aware SVG routing while retaining the 0.1 component and connection syntax.

## Net membership

```edsl
NET POWER {
    F1.2;
    J1;
    L1.L;
}
```

Every member is electrically connected to the first member. A named net must contain at least two members.

## Junctions

```edsl
JUNCTION J1;
```

A junction may be used as a connection or net endpoint without a terminal suffix. The SVG renderer draws it as a filled connection dot.

## Route preferences

```edsl
CONNECT L1.N -> F1.1 {
    route = "below"
}
```

Supported preferences are `auto`, `above`, and `below`. Automatic routes use orthogonal segments and move to an outside routing channel when a candidate path intersects another component.

## Validation

The CLI checks language versions, duplicate component IDs, component types, terminal names, junction references, duplicate nets, and net membership counts before build or export.

```powershell
node packages/cli/dist/index.js check examples/v02-panel.edsl
node packages/cli/dist/index.js build examples/v02-panel.edsl
```
