# ElectroDSL 0.8 electrical integrity

ElectroDSL 0.8 adds semantic connectivity analysis to the production quality gate.

## Integrity checks

- Self-connected electrical paths are errors.
- Duplicate paths between the same endpoints are errors.
- Conductors referencing undeclared cables are errors.
- Allocating more conductors than a cable has cores is an error.
- Electrically isolated components are warnings.
- Cross-sheet ports present on only one sheet or unconnected on a sheet are warnings.

Warnings are reported but do not fail a build. Errors prevent output generation.

## Production workflow

```powershell
node packages/cli/dist/index.js project check examples/project-v08 --json
node packages/cli/dist/index.js project build examples/project-v08
node packages/cli/dist/index.js project verify examples/project-v08
```

Successful builds include `connectivity.json`, containing circuit statistics, isolated devices, cross-sheet port status, and project totals. It is protected by the SHA-256 artifact manifest.

Version 0.8 retains the language constructs introduced in 0.1–0.7. The integrity rules activate for 0.8 documents so older projects can migrate deliberately.
