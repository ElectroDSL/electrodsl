# ElectroDSL 0.5 Tooling and Ecosystem

Status: Stable (`0.5.0`). The 0.5 language remains backward compatible with 0.4 and standardizes the first editor, package, interchange, governance, and AI-assistance APIs.

## Language service and LSP

- `@electrodsl/language-service` provides diagnostics, zero-based ranges, completions, hover documentation, and formatting.
- `@electrodsl/language-server` provides standard JSON-RPC/LSP framing over stdio, document synchronization, live diagnostics, completion, hover, and formatting.
- `editors/vscode` registers `.edsl`, syntax highlighting, brackets, and the language configuration used by a VS Code client package.
- `edsl diagnose <file> --json` supports editor and CI integrations; `edsl lsp --stdio` starts the language server.

## Package manifest

An `edsl-package.json` file identifies a namespaced library, semantic version, compatible language range, license, exported components/modules, and dependencies. The resolver supports exact versions, wildcard selection, and same-major caret ranges. Transitive resolution creates deterministic `electrodsl-lock/0.5` lockfiles with SHA-256 manifest integrity and detects unavailable packages, incompatible constraints, and dependency cycles.

## Interchange adapters

`@electrodsl/adapters` provides a registry for independently developed import/export formats. The built-in canonical JSON adapter exports the stable IR. The CSV netlist adapter imports and exports components, modules, ports, instances, junctions, connections, conductors, cables, nets, and buses.

## AI assistance

`@electrodsl/ai-tools` builds constrained generation prompts, validates generated source, explains project structure, and produces conservative optimization hints. These APIs never represent their results as electrical safety approval; qualified engineering review remains required.

## Governance

Syntax, semantic, canonical-IR, and diagnostic-family changes use the public process under `rfcs/`. Accepted changes require specification text and executable conformance fixtures.
