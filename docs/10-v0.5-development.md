# ElectroDSL 0.5 Development

Status: Development preview (`0.5.0-dev.1`). The 0.5 language remains backward compatible with 0.4 while editor and ecosystem APIs mature.

## First development milestone

- Editor-neutral language service with diagnostics, zero-based source ranges, completions, hover documentation, and formatting
- `edsl diagnose <file> --json` for editor and CI integration
- Versioned package manifest, validation, deterministic in-memory resolution, and JSON Schema
- Public RFC process and proposal template
- AI schema generator repaired to emit valid, parseable ElectroDSL 0.5

## Package manifest

An `edsl-package.json` file identifies a namespaced library, semantic version, compatible ElectroDSL language range, license, exported components/modules, and dependencies. The development resolver supports exact versions, wildcard selection, and same-major caret ranges.

## Language service

`@electrodsl/language-service` is protocol-neutral so a VS Code extension, browser editor, CLI, or Language Server Protocol wrapper can share identical behavior. Its public operations are `diagnose`, `format`, `complete`, and `hover`.
