# ElectroDSL 0.7 project quality gates

ElectroDSL 0.7 makes validation a mandatory part of production generation. A project is parsed and checked as one engineering model before any drawing or report is written.

## Check a project

```powershell
node packages/cli/dist/index.js project check examples/project-v07
node packages/cli/dist/index.js project check examples/project-v07 --json
```

The quality gate checks language versions, project identity, duplicate project-wide circuit and module names, component and terminal references, engineering values, nets, and route preferences. Errors return a failing process exit code suitable for CI.

## Build behavior

`project build` runs the same quality gate first and refuses to generate partial or misleading output when errors exist. Successful builds include `quality.json`, and the file is covered by the artifact manifest.

The JSON contract is `electrodsl-quality/0.7`. Project and artifact manifests use `electrodsl-project/0.7` and `electrodsl-artifacts/0.7`. Version 0.6 project manifests remain readable for migration.
