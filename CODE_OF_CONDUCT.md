# ElectroDSL Code of Conduct

## Our Commitment

We are committed to making participation in the ElectroDSL community a welcoming, respectful, and collaborative experience for everyone.

ElectroDSL is an international open-source engineering project. We welcome contributors regardless of experience level, nationality, gender, age, disability, ethnicity, religion, or professional background.

Our goal is to build a professional community focused on advancing open standards for electrical engineering.

---

# Our Values

Members of the ElectroDSL community are expected to:

- Be respectful.
- Be professional.
- Be constructive.
- Be collaborative.
- Be patient with new contributors.
- Share knowledge openly.
- Welcome feedback.
- Focus discussions on technical merit.

---

# Expected Behavior

Examples of positive behavior include:

- Using welcoming and inclusive language.
- Respecting differing technical opinions.
- Accepting constructive criticism.
- Helping newcomers.
- Keeping discussions focused on improving ElectroDSL.
- Providing evidence when proposing architectural changes.
- Respecting project decisions once consensus has been reached.

---

# Unacceptable Behavior

The following behaviors are unacceptable:

- Harassment or discrimination.
- Personal attacks.
- Insults or abusive language.
- Trolling or intentionally disruptive behavior.
- Publishing private information without permission.
- Spam or advertising unrelated to ElectroDSL.
- Deliberately damaging project infrastructure.

---

# Engineering Discussions

ElectroDSL encourages technical debate.

Disagreements are expected and often improve the project.

When discussing design decisions:

- Explain your reasoning.
- Provide technical evidence.
- Respect alternative viewpoints.
- Focus on solving engineering problems rather than winning arguments.

---

# Scope

This Code of Conduct applies to:

- GitHub Issues
- Pull Requests
- Discussions
- Documentation
- Project website
- Community communication channels

---

# Maintainer Responsibilities

Project maintainers are responsible for:

- Enforcing this Code of Conduct fairly.
- Reviewing reports objectively.
- Encouraging respectful collaboration.
- Maintaining a welcoming environment.

Maintainers may edit, remove, or reject content that violates this Code of Conduct.

---

# Reporting Issues

If you experience or witness behavior that violates this Code of Conduct, please contact the project maintainers through GitHub Issues or Discussions.

Reports will be reviewed respectfully and confidentially whenever possible.

---

# Enforcement

Violations may result in:

1. Warning
2. Temporary restriction
3. Permanent removal from the project community

The severity of the response depends on the nature and frequency of the violation.
